# GameHUD

Displays level number and stage timer on the HUD (Tab key or always-on).

R.E.P.O. BepInEx mod. Host-side only.

## Install

Requires [BepInEx 5.x](https://thunderstore.io/c/repo/p/BepInEx/BepInExPack/).

Place `GameHUD.dll` in `BepInEx/plugins/`.

## Configuration

Edit `BepInEx/config/maxenterme.GameHUD.cfg` after first launch.

## Build

```
dotnet build -c Release
```
